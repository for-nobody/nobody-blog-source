#### 前言
既然多窗口也搞定了，你一定想知道怎么把这个程序发给别人玩。如果你直接把 `build` 文件夹里的 `.exe` 发给朋友，他双击会报错：**“找不到 Qt6Core.dll”**。
这是因为 Qt 程序运行需要一堆“库文件（DLL）”。

#### 官方打包神器：windeployqt
1. **找到你的编译器文件夹：** 在你的 Qt 安装目录下（例如 `C:\Qt\6.x\mingw_64\bin`）。
2. **打开命令提示符 (CMD)：**
3. **输入命令：**
    ```Bash
    windeployqt C:\你的项目路径\test.exe
    ```
4. **奇迹发生：** 这个工具会自动把所有需要的 `.dll` 文件统统拷贝到你的 `.exe` 旁边。

#### 如何实现单文件的打包-静态打包
把一大堆 `.dll` 塞进一个 `.exe` 叫作“静态打包”。
默认情况下，Qt 是动态链接的（即 `.exe` 依赖外部 `.dll`）。要变成一个独立的 `.exe`，通常有两种方法：
##### 方法 A：静态编译（硬核但彻底）
你需要自己下载 Qt 源码，用编译器重新编译一遍整个 Qt 框架，并在配置时指定 `-static` 参数。
- **优点：** 官方原生支持，性能最好。
- **缺点：** 极其耗时（编译一次可能要几小时），且对开源版有更严格的 GPL 协议限制。
##### 方法 B：使用 Enigma Virtual Box（简单快捷，推荐初学者）
这是一种“伪静态”打包。它的原理是将你的 `.exe` 和所有 `.dll` 包装在一个虚拟的文件箱里。
1. 先用我之前教你的 `windeployqt` 命令，把所有 `.dll` 补齐到一个文件夹里。
2. 下载并安装免费的 **Enigma Virtual Box**。
3. **Enter Input File Name:** 选择你的 `test.exe`。
4. **Enter Output File Name:** 选择你想要生成的单文件路径。
5. **Files Tree:** 把文件夹里剩下的所有 `.dll` 和文件夹拖进去。
6. 点击 **Process**。
- **结果：** 你会得到一个体积较大（因为它包含了所有库）但可以直接单文件运行的 `.exe`。

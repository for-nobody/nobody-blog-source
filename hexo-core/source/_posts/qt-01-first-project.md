## 零 前提
### QT UI的分类
| **特性**   | **Qt Widgets (经典派)** | **Qt Quick/QML (现代派)** |
| -------- | -------------------- | ---------------------- |
| **编程语言** | C++                  | QML (类似 JS/CSS) + C++  |
| **适用场景** | 传统的桌面软件（如：网盘、IDE）    | 触屏界面、手机 App、动效丰富的 UI   |
| **上手难度** | 需要一定的 C++ 基础         | 上手快，界面逻辑分离             |
### 信号与槽 (Signals & Slots)
这是 Qt 的灵魂。简单来说，它解决了“当一个按钮被点击时，程序该执行什么逻辑”的问题。
- **信号 (Signal)：** 发生的事件（例如：按钮被点了一下）。
- **槽 (Slot)：** 处理事件的函数（例如：关闭窗口、保存文件）。
- **连接 (Connect)：** 你只需要一行代码或者在 UI 设计器里拉一条线，把它们连起来。
### 文件总览
#### **CMakeLists.txt (施工蓝图)**
这是项目的“指挥官”。它告诉编译器：
- 我们需要用到 Qt 的哪些模块（比如 `Widgets`）。
- 哪些 `.cpp` 文件需要被编译。
- 哪些 `.ui` 文件需要转换成 C++ 代码。
> **新手笔记：** 你暂时不需要手动修改它，但记得：如果你以后给项目添加了新的图片或第三方库，都要在这里“打报告”。
#### **main.cpp (启动开关)**
这是程序的入口点。
```C++
int main(int argc, char *argv[]) {
    QApplication a(argc, argv); // 管理程序的生命周期、事件循环
    test w;                     // 创建你写的那个窗口对象
    w.show();                   // 把窗口显示出来
    return a.exec();            // 让程序进入“待命状态”，等待你的点击
}
```
#### **test.h & test.cpp (大脑与逻辑)**
- **`test.h`**：定义了窗口长什么样，有哪些功能。
    - 你会看到 `Q_OBJECT` 这个宏，它是 Qt 的“魔法核心”，有了它才能使用**信号与槽**。
- **`test.cpp`**：实现具体的功能。
    - `ui->setupUi(this);` 这行代码至关重要，它负责把你在 UI 设计器里画的东西“翻译”并加载到代码中。
#### **test.ui (视觉设计)**
这是一个 XML 格式的文件。当你双击它时，Qt Creator 会自动开启 **Qt Designer**。它让你不需要写代码就能布局界面。

## 一 创建
### Step 1:
打开 **Qt Creator**，点击 **"New Project"**，选择 **"Qt Widgets Application"**。
### Step 2:
- build system选择cmake for qt5 and qt6

| **特性**      | **CMake (推荐)**                  | **qmake (传统)**         |
| ----------- | ------------------------------- | ---------------------- |
| **行业地位**    | C++ 事实上的行业标准，通用性极强              | 仅限于 Qt 项目，正逐渐被边缘化      |
| **Qt 版本支持** | 完美支持 Qt 5.15+ 和 **Qt 6 (原生构建)** | Qt 5 的主力，但 Qt 6 仅为兼容提供 |
| **三方库集成**   | 极度方便（配合 `vcpkg` 或 `conan`）      | 非常痛苦，通常需要手动配置路径        |
| **构建速度**    | 配合 Ninja 构建工具，速度极快              | 相对较慢                   |
| **维护状态**    | 持续更新，功能日益强大                     | 仅维护，不再增加新功能            |
### Step 3：
#### detail选择：
- **Class Name (类名):** 这是你窗口类的名字。
    - **建议：** 默认通常是 `MainWindow` 或 `Widget`。如果你在做一个记事本，可以改名为 `Notepad`。首字母务必大写。
- **Base Class (基类):**  这是最重要的选择，决定了你窗口的“基因”：  **`QMainWindow`:** 最常用。自带菜单栏、状态栏、工具栏。适合做功能完整的桌面软件。  **`QWidget`:** 最基础的空白面板。没有菜单栏，适合做简单的插件、自定义控件或小窗口。  **`QDialog`:** 对话框。通常带有“确定/取消”按钮，适合做弹窗、设置界面。
- **Header / Source File (头文件与源文件):**  这是存放 C++ 代码的文件名。
    - **建议：** 保持默认（通常与类名同名，小写）。例如类名是 `MainWindow`，文件名就是 `mainwindow.h` 和 `mainwindow.cpp`。
- **Generate Form (生成表单 / .ui 文件):**  
	- **勾选（强烈建议）：** 如果你想通过“拖拽”来设计界面，就一定要勾选。它会生成一个 `.ui` 文件。
    - **不勾选：** 你需要完全通过 C++ 代码一行行写出界面（适合高手或动态界面）。

|**你的目标**|**基类 (Base Class) 选择**|**是否勾选 Generate Form**|
|---|---|---|
|**做一个标准的桌面软件**|`QMainWindow`|**是** (新手最推荐)|
|**做一个登录界面或设置弹窗**|`QDialog`|**是**|
|**做一个嵌入在其他窗口里的组件**|`QWidget`|**是**|
|**纯代码练习 / 深度自定义 UI**|任意|**否**|
### Step 4：
- 构建套件：
	**构建套件 (Kit)** 简单来说就是一套工具箱，它告诉 Qt Creator 用哪个编译器、哪个版本的 Qt 库以及为哪个平台（Windows/Android/Embedded）构建程序。
	### 1. 应该勾选哪一个？
	如果你在安装时选择了默认组件，你可能会看到类似下面的选项：
	- **Desktop Qt 6.x.x MinGW 64-bit:** **(首选推荐)**
	    - **理由：** MinGW 是一个开源的编译器（GCC 的 Windows 版），它安装简单，对标准 C++ 支持很好，非常适合学习和练习。
	- **Desktop Qt 6.x.x MSVC 2019/2022:** **(备选)**
	    - **理由：** 这是微软的编译器。如果你电脑上装过 Visual Studio，这个选项会出现。它在性能优化和调试大型商业项目时很有优势，但初学者配置起来可能稍显麻烦。
	- **Android / WebAssembly:** **(先不要选)**
	    - **理由：** 这些是跨平台开发用的。如果你现在只是在电脑上跑个小窗口，勾选它们只会增加编译负担。
	### 2. 状态图标代表什么？
	在 Kit 名字前面通常会有个小图标：
	- **蓝色星号/勾选：** 正常的、配置完好的 Kit，可以直接使用。
	- **黄色感叹号：** 配置有缺失。可能是你装了 Qt 库但没装编译器，或者路径没对上。
	- **红色感叹号：** 无法工作，通常是编译器或 Qt 版本完全找不到了。
### Step 5：
- 完成

## 二 设计：点击按钮以改变文字内容
### 动手实现第一个功能：点击按钮弹窗
既然项目已经建好了，我们来做一个最经典的测试：**点击按钮，改变文字内容。**
#### 第一步：设计 UI
1. 在左侧列表双击 **`test.ui`**。
2. 在左侧组件库找到 **Label**（标签），拖到窗口中间，双击它改名为“等待点击”。
3. 找到 **Push Button**（按钮），拖到窗口里，双击它改名为“点我”。
4. 在右下角的属性栏里，把这个按钮的 `objectName` 改为 `btn_test`（方便在代码里找到它）。
#### 第二步：关联信号与槽（核心步骤）
1. 在 UI 界面上，右键点击你刚放上去的**按钮**。
2. 选择 **“转到槽...” (Go to slot...)**。
3. 在弹出的对话框中选择第一个 `clicked()`，点击确定。
4. **奇迹发生了：** Qt Creator 会自动跳转到 `test.cpp`，并帮你生成了一个函数：
```C++
void test::on_btn_test_clicked() {
        // 这里就是点击按钮后会执行的代码
}
```
#### 第三步：编写逻辑
在刚才生成的函数里加入一行代码：
```C++
void test::on_btn_test_clicked()
{
    // ui 指针指向的就是你的界面，label 是那个标签的名字
    ui->label->setText("你好，Qt！项目运行成功！");
}
```
#### 第四步：运行你的项目
点击 Qt Creator 左下角的 **绿色三角形图标 (Run)**。
- **编译过程：** CMake 会开始工作，处理你的文件。
- **结果：** 弹出一个空白窗口，上面有你放的标签和按钮。点击按钮，标签文字就会瞬间改变。
### 常见小问题
- **报错 "collect2: error: ld returned 1 exit status":** 这通常是因为你之前的程序还在运行，窗口没关，导致无法写入新的程序。**关掉之前的测试窗口再点运行**即可。
- **找不到 UI 组件：** 如果你在代码里输入 `ui->` 后面没提示你的按钮名字，按一下 `Ctrl + Shift + B`（构建项目），Qt 就会重新刷新 UI 索引。

**恭喜你完成了第一个 Qt 项目！**

### 写在之后：
#### **核心灵魂：信号与槽 (Signals & Slots)**
这是 Qt 最引以为傲的机制。你可以把它想象成“广播站”与“收音机”：
- **信号 (Signal)**：当某个事件发生时发出的广播。例如：按钮被点击了 (`clicked`)。
- **槽 (Slot)**：接收到广播后执行的动作。例如：你写的 `on_btn_test_clicked()` 函数。
#### **对象树 (Object Tree)**
在 Qt 中，当你给一个控件（比如 Label）指定了父窗口（Parent）后，你不需要手动去 `delete` 它。
- **原理**：当父窗口（你的 `test` 类）销毁时，它会自动把肚子里所有的子控件统统销毁。这帮你省去了很多内存管理的烦恼。
#### **布局管理器 (Layouts)**
初学者最容易犯的错误是“写死位置”。如果你直接拖动按钮，缩放窗口时按钮位置会乱掉。
- **解决**：选中背景，点击工具栏上的 **"Lay Out Vertically"**（垂直布局）或 **"Lay Out Horizontally"**（水平布局）。这样你的界面就能自动随窗口大小伸缩了。

## 三 设计 输入文本并点击按钮以显示输入内容
### 为它添加一个功能：让你输入一段文本，按下按钮，在label标签上显示内容
#### 第一步：在 UI 界面添加输入框
1. 双击项目中的 `test.ui` 进入设计模式。
2. 在左侧组件库（Widget Box）中找到 **Line Edit**（输入框），把它拖到窗口里。
3. **关键动作：** 选中这个输入框，在右侧的“属性编辑器”里，把 `objectName` 修改为 `inputName`。
4. （可选）把之前的按钮（Push Button）文字改为“点击打招呼”，把标签（Label）文字改为“等待输入...”。
#### 第二步：编写联动代码
1. 回到你的 `test.cpp` 文件。
2. 找到你之前生成的那个槽函数 `on_btn_test_clicked()`（如果你改了按钮名字，建议重新右键按钮点击“转到槽”来生成正确的函数名）。
3. 将函数体内的代码修改为：
```C++
void test::on_btn_test_clicked()
{
    // 1. 从输入框（inputName）中获取用户输入的文本
    QString name = ui->inputName->text();

    // 2. 检查输入是否为空（基础逻辑判断）
    if (name.isEmpty()) {
        ui->label->setText("你还没输入名字呢！");
    } else {
        // 3. 拼接字符串并显示在标签上
        ui->label->setText("你好，" + name + "！欢迎来到 Qt 世界。");
    }
}
```
#### 第三步：理解背后的知识点
在这个小演示中，你学到了三个非常重要的 Qt 概念：
1. **QString（Qt 字符串类）：** Qt 不常用 C++ 标准库的 `std::string`。`QString` 是 Qt 专门设计的，它支持强大的中文处理、拼接（用 `+` 号就行）和各种转换。它是你以后处理文字最常用的工具。
2. **UI 指针（`ui->`）：** 所有在 `.ui` 文件里创建的控件，在 `.cpp` 里都必须通过 `ui->` 这个指针来访问。`inputName` 和 `label` 都是它的成员。
3. **属性访问（Getter 和 Setter）：**
    - `text()`：这是一个 **Getter**，用来获取控件当前的文本。
    - `setText()`：这是一个 **Setter**，用来设置控件显示的文本。
    - 你会发现 Qt 的函数命名非常有规律，几乎所有的控件都有类似的函数。
### 进阶一个小功能：尝试一边输入，label标签跟着变化
1. 回到 `test.ui`，右键点击**输入框**（Line Edit）。 
2. 选择“转到槽...”，这次选择 **`textChanged(QString)`** 信号。
3. 在生成的函数里写：
```C++
void test::on_inputName_textChanged(const QString &arg1) {
    ui->label->setText("实时预览：" + arg1);
}
```
4. 你会发现，你每敲一个字符，标签都会瞬间同步更新！这就是 Qt 信号与槽的强大之处。

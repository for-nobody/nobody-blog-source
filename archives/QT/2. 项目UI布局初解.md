### 三种基本布局
- **Vertical Layout (垂直布局):** 把控件像叠罗汉一样，从上往下整齐排列。
- **Horizontal Layout (水平布局):** 把控件像排队一样，从左往右横向排列。
- **Grid Layout (网格布局):** 像 Excel 表格一样，把控件放在行和列里，适合复杂的表单。

### 开始
#### **第一步：打破原有的“死板”位置**
1. 打开 `test.ui`。
2. 如果你之前把控件放得很乱，没关系。
3. **关键动作：** 在窗口的**空白处**右键点击，选择 **布局 (Lay Out)** -> **垂直布局 (Lay Out Vertically)**。
    - _你会发现：_ 所有的控件瞬间自动填满了整个窗口，并且整齐地上下排列。
#### **第二步：组合局部布局**
有时候我们希望输入框和按钮在一行，而标签在另一行。这时候需要“嵌套”：
1. 先按下 `Ctrl + Z` 撤销刚才的全窗口布局。
2. 选中**输入框**和**按钮**（按住 Ctrl 键多选）。
3. 在上方工具栏点击 **“水平布局” (Lay Out Horizontally)** 图标。现在它们两个被框在了一个红框里。
4. 现在，点击窗口空白处，再次点击工具栏的 **“垂直布局” (Lay Out Vertically)**。
    - _结果：_ 输入框和按钮并排在上方，标签在下方，整个界面非常和谐。
#### **第三步：使用弹簧 (Spacer)**
如果你觉得控件之间太挤，或者想让按钮靠左/靠右：
1. 在左侧组件库找到 **Horizontal Spacer**（水平弹簧）。
2. 把它拖到输入框和按钮中间。
    - _效果：_ 弹簧会把两边的控件往两头推。

### 其他的理论
#### 布局的核心属性
当你选中一个布局（红框）时，可以在右侧属性栏调整：
- **layoutSpacing:** 控件之间的间距。
- **layoutContentsMargins:** 布局与窗口边缘的距离（留白）。
- **sizePolicy:** 决定了当窗口变大时，哪个控件吃掉剩余空间（比如让输入框变长，而按钮保持原样）。
#### 为什么要在代码外做布局？
虽然你可以用代码写布局（如 `QVBoxLayout *layout = new QVBoxLayout;`），但**强烈建议初学者先在 UI 设计器里做**。原因有二：
1. **所见即所得：** 你不需要反复编译就能看到缩放效果。
2. **代码简洁：** 你的 `.cpp` 文件只需要关注业务逻辑，而不需要处理烦人的像素坐标。

### 继续
#### 限制控件的尺寸 (Size Constraints)
在 Qt 中，每个控件都有四个关键属性，你可以在 UI 设计器的右侧**属性栏（Property Editor）**中找到它们：
- **`minimumSize` (最小尺寸)：** 控件再怎么压缩也不能小于这个值。例如，你可以把按钮设为 $80 \times 30$，防止它缩成一个点。
- **`maximumSize` (最大尺寸)：** 控件再怎么拉伸也不能大于这个值。如果你不想让输入框变得像面条一样长，可以限制它的宽度。
    - _小技巧：_ 如果你想固定死大小，把最小和最大设成一样即可。
- **`sizePolicy` (尺寸策略)：** 决定控件如何“抢占”空间。
    - **Fixed:** 严格遵守设置的大小。
    - **Expanding:** 尽可能地占据所有能拿到的空间（适合输入框或文本框）。
#### 给界面更换风格：样式表 (Qt Style Sheets)
Qt 的样式表（QSS）语法和网页开发的 **CSS** 几乎一模一样。你可以通过它修改颜色、边框、圆角甚至背景图。
-  **如何设置？**
1. 在 UI 设计器中，右键点击你的窗口背景或某个按钮。
2. 选择 **“改变样式表...” (Change style-sheet...)**。
3. 在弹出的文本框里输入代码。
- 美化按钮 (Push Button)
```CSS
QPushButton {
    background-color: #4CAF50; /* 绿色背景 */
    color: white;               /* 白色文字 */
    border-radius: 10px;        /* 圆角 */
    border: 2px solid #3e8e41;  /* 深绿边框 */
    padding: 5px;               /* 内边距 */
}

QPushButton:hover {
    background-color: #45a049; /* 鼠标悬停时变色 */
}

QPushButton:pressed {
    background-color: #2e5e30; /* 按下时变深 */
}
```

- 美化输入框 (Line Edit)
```CSS
QLineEdit {
    border: 2px solid gray;
    border-radius: 5px;
    padding: 0 8px;
    background: #f0f0f0;
    selection-background-color: darkgray;
}
```
- 全局皮肤 vs 局部修改
	- **局部修改：** 像上面那样右键点击单个控件设置。只有该控件（及其子控件）受影响。
	- **全局修改：** 在 `main.cpp` 中给整个 `QApplication` 设置样式。
```C++
	// 在 main.cpp 中
    a.setStyleSheet("QPushButton { color: red; }"); 
    //这样你程序里所有的按钮的文字颜色都会变成红色。
```
>	说明：在全局修改中，如果想要对于整个QApplication设置样式，想要对于其中的按钮的文字颜色都设计为红色，但是如果之前在项目按钮btn_test的样式表里写下了
```CSS
	QPushButton {
    background-color: #4CAF50; /* 绿色背景 */
    color: white;               /* 白色文字 */
    border-radius: 10px;        /* 圆角 */
    border: 2px solid #3e8e41;  /* 深绿边框 */
    padding: 5px;               /* 内边距 */
	}
	
	QPushButton:hover {
	    background-color: #45a049; /* 鼠标悬停时变色 */
	}
	
	QPushButton:pressed {
	    background-color: #2e5e30; /* 按下时变深 */
	}
```
>	这样美化按钮的CSS代码，那么最终的按钮样式会是**这个按钮自己的样式表完全覆盖全局修改的样式**，文字颜色仍为白色。
>	样式表的执行规则：
>	1. **后设置的覆盖先设置的**
>	2. **控件级别 > 窗口级别 > 应用级别**
>	3. **更具体的选择器 > 通用选择器**
>	4. **完整的样式表会完全替换之前的样式表**

### 小练习
#### 题目
- 给你的 **Label** 设置一个醒目的背景色（如 `background-color: yellow;`）并加一个边框。
- 把 **Push Button** 的最大高度（`maximumHeight`）限制在 40 像素。
- 尝试把窗口的背景色改为浅蓝色：
    - 右键窗口空白处 -> 改变样式表 -> 输入 `QWidget { background-color: #e0f0ff; }`。
#### 解答
##### 1. Label 的美化（黄色背景+边框）
**操作：** 右键 Label -> “改变样式表”
```CSS
QLabel {
    background-color: #FFFFCC; /* 浅黄色 */
    border: 2px solid #FFA500; /* 橙色边框 */
    border-radius: 5px;        /* 圆角 */
    padding: 10px;             /* 文字离边框远一点，更好看 */
    font-size: 14px;           /* 字体加到14像素 */
    color: #333333;            /* 深灰色文字 */
}
```
##### 2. 限制按钮高度
**操作：** 选中按钮 -> 在右侧属性栏（Property Editor）找到 `maximumSize`。
- 将 **Height**（高度）设为 **40**。
- 这样即便你用了垂直布局，按钮也不会被无限拉高，显得很滑稽。
##### 3. 窗口背景色
**操作：** 右键点击主窗口（注意不要点到控件上） -> “改变样式表”
```CSS
/* 注意：这里用类名 Test 是因为你的类名是 Test */
QWidget#Test { /*#Test而不是#test*/
    background-color: #E0F0FF; 
}
```
> **排雷小贴士：** 有时候直接写 `QWidget { background-color: white; }` 会导致窗口里的所有按钮、标签也全变成白色背景。使用 `#对象名`（如 `#Test`）可以精准地只给窗口背景上色。

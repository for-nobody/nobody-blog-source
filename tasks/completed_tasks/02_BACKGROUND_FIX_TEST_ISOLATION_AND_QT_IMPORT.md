#### 背景复现与修复

原型的根元素背景透明，入场结束后旋涡仍可见。正式站点的 `html` 和 `body` 都有不透明底色。`pageEnter` 运行期间，`body` 的透明度创建临时层叠上下文。动画结束后该上下文消失，`z-index: -2` 的旋涡被 `body` 底色覆盖。在实际 Hexo 预览的 DevTools 临时把 `html` 或 `body` 底色设为透明，或给 `body` 设置 `isolation: isolate`，均可恢复旋涡。最终只在共用 `site.css` 添加 `body { isolation: isolate; }`，让层叠上下文在动画前后持续存在，保留原有配色和入场动画。
